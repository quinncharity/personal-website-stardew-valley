# Charity Quinn – Stardew Valley-Inspired Personal Portfolio

This repository contains the source code for my personal portfolio website, themed around the cozy, pixel-art aesthetic of Stardew Valley.  
It showcases my background, projects, and an interactive game-like experience built with React.

## Tech Stack

- **Framework**: React 18
- **Bundler/Dev Server**: Vite
- **Language**: TypeScript

## Run Locally

**Prerequisites**: Node.js (LTS recommended) and npm

1. Install dependencies:  
   `npm install`
2. Start the development server:  
   `npm run dev`

The app should now be available at the URL printed in your terminal (typically `http://localhost:5173`).

## Build for Production

To create an optimized production build:

```bash
npm run build
```

You can then preview the production build locally with:

```bash
npm run preview
```

This generates static assets in the `dist` directory, which can be deployed to any static hosting service.
